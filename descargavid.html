Panel de Control: GitHub Pages Edition

Debido a que GitHub Pages es un servidor estático, usamos métodos especiales para burlar la seguridad del navegador y poder extraer videos de otras páginas.

Método 1: El Marcador Mágico (Recomendado)

Funciona en cualquier web. Se ejecuta directamente en la pestaña del video.

Instrucciones de Instalación:

  1. Asegúrate de que la barra de marcadores de tu navegador esté visible (Ctrl+Shift+B).
  2. Arrastra el botón azul de abajo hacia tu barra de marcadores.
  3. Ve a la página de donde quieres descargar el video (ej. TikTok, Vimeo, etc.).
  4. Haz clic en el marcador que guardaste. ¡Te traerá de vuelta aquí con los videos detectados!
Arrástrame a Marcadores (Sniffer)

Método 2: Extracción por Proxy

Pega la URL arriba. El sistema descargará el HTML crudo y buscará etiquetas de video.

* Nota: Este método no funciona bien para sitios como YouTube que cargan los videos dinámicamente con JavaScript (Blob URLs), pero es excelente para sitios web normales y blogs.
